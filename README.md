# 📖 Project Overview

This project demonstrates practical **log analysis** using Linux command-line utilities. Three Apache web server log datasets were analyzed to extract useful information about web traffic, client requests, HTTP response codes, and user activity.

The investigation involved identifying request patterns, counting HTTP methods, analyzing status codes, discovering unique IP addresses, examining User-Agent strings, and documenting the findings in a professional report.

---

# 🎯 Project Objectives

- Analyze Apache web server log files
- Count HTTP GET requests
- Identify unique IP addresses
- Examine HTTP status codes
- Detect HTTP CONNECT requests
- Analyze User-Agent strings
- Identify frequently accessed resources
- Produce a professional log analysis report
